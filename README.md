# Sales Intelligence Platform

Full-stack Sales Intelligence Platform with AI Voice Consultant, Drill-down Analytics, and What-If Simulator.

## 🏗️ Architecture

- **Backend**: ASP.NET Core Web API (.NET 10), Entity Framework Core, PostgreSQL, MailKit, Edge TTS
- **Frontend**: React, TypeScript, Vite, Modern Responsive UI & Glassmorphism Theme System

## 🚀 Getting Started

### Backend (.NET API)
```bash
cd backend/SalesIntelligence.Api
dotnet restore
dotnet run
```

### Frontend (React + Vite)
```bash
cd frontend
npm install
npm run dev
```
